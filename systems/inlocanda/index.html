The System INLOCANDA


The system can be downloaded here.

Syntax:

java -jar LOCANDA.jar -et <value> -s <value> -t <value> -m <value>
-et float value: lower threshold on the edge weight (inclusive)
-s true|false: remove symmetry
-t int value: maximum length of a path in the network. 0 = no limit
-m Avg|Product|Max|Min|Mycin: measure computed on the path.


G. Pio, M. Ceci, F. Prisciandaro, D. Malerba, Exploiting causality in Gene Network Reconstruction based on graph embedding, Machine Learning 109, 1231-1279 (2020). https://doi.org/10.1007/s10994-019-05861-8
